馬達的 IE 效率等級（IE1~IE5）常被當成一句話帶過——「這顆是 IE3」。但實務上要準確判定一顆馬達屬於哪個等級，牽涉到選對標準、確認適用範圍、用正確的基準點量測，最後才是查表或套公式。這篇整理判斷流程，特別標出泵浦（pump）、風扇（fan）這類應用容易踩到的雷。

---

## 第一步：先分清楚該用哪份標準

「IE 等級」不是單一標準，依馬達的供電方式分成兩份完全不同的文件：

| | IEC 60034-30-1 | IEC TS 60034-30-2 |
|---|---|---|
| 適用對象 | 市電直驅（on-line/grid）馬達，50/60Hz 正弦波供電 | 變頻器驅動（variable speed）的馬達 |
| 涵蓋馬達類型 | 感應馬達為主 | 感應馬達（限變頻驅動）、永磁同步馬達（PMSM，含或不含磁阻轉矩成分）、同步磁阻馬達、直流激磁同步馬達 |
| 判定基準點 | 額定轉速、額定負載下直接量測 | 90% 額定轉速、額定轉矩下量測（見第三步） |

**判斷原則：**
- 馬達直接接市電運轉 → 用 30-1
- 馬達由變頻器驅動、非市電直驅 → 用 30-2
- 同時支援兩種運轉方式的「雙額定馬達」（例如 line-start PM motor）→ 一律用 30-1 的規則

PMSM／BLDC 這類馬達幾乎都是變頻驅動，很容易直接套用大家熟悉的 30-1 概念去理解「IE3」，但實際上該對照的是 30-2 的判定邏輯，兩者的量測基準點和門檻表都不一樣，不能混用。

## 第二步：確認馬達在不在涵蓋範圍內

在計算任何數字之前，先過這張清單，任一項不符合，這份標準就不適用：

| 條件 | 數值 |
|---|---|
| 額定功率 PN | 0.12 kW ~ 1000 kW |
| 額定電壓 UN | 50 V ~ 1 kV |
| 額定轉速 nN | 600 ~ 6000 rpm（**與極數無關**） |
| 冷卻方式 | IC410 / IC411 / IC416 / IC418（依 IEC 60034-6） |
| 運轉型態 | 連續運轉 S1，或 S3~S10 且工作週期 ≥80% |
| 環境溫度 | -20°C ~ +60°C |
| 海拔 | ≤4000 m |
| 非 servo 應用 | 見下方判定式 |

### ⚠️ 特別注意：一體式設計（尤其是 pump / fan / compressor）

標準原文明確排除：

> Motors completely integrated with the driven machine (for example pumps, fans and compressors) that cannot be practically tested separately from the machine

白話講：如果馬達跟被驅動的機構（幫浦葉輪、風扇扇葉、壓縮機構）做成一體式設計，沒辦法把馬達單獨拆下來獨立測效率，這份標準**直接不適用**——不是「等級比較低」，而是根本沒有 IE 等級可言。這是實務上最容易誤判的地方：很多幫浦馬達、風扇馬達的效率規格是整組成品測出來的，而不是馬達本體單獨測試，遇到這種情況要先確認測試數據的來源，再決定能不能往下判定。

### Servo 應用排除判定式

只要滿足下列任一式，該馬達視為 servo motor，不適用本標準（$P_N$ 單位 kW）：

- 最高轉速：$n_{max} > 6000 \cdot e^{-0.02 P_N - 0.4} + 3200$（1/min）
- 角加速能力：$\dfrac{T_{max}}{J} > 18000 \cdot e^{-1.3P_N - 1} + 5800$（1/s²）

## 第三步：用正確的基準點量測效率

這是最容易搞錯的一步。**IE 等級判定不是用馬達在額定點（100% 轉速、100% 負載）量到的效率**，而是在 **90% 額定轉速、額定（或滿載）轉矩** 這個工作點量測：

$$P_{90} = 0.9 \cdot P_N, \quad n_{90} = 0.9 \cdot n_N$$

若製造商未提供額定轉矩 $T_N$，用下式反推滿載轉矩：

$$T_{100} = \dfrac{P_N}{2\pi n_N}$$（$P_N$ 單位 W，$n_N$ 單位 1/s）

選 90% 而非 100% 的原因：確保磁通已達額定值、不受變頻器內部電壓降影響，同時跟變頻器（CDM）測試條件對齊。量到 η₉₀ 之後，還要扣除變頻器產生的諧波額外損耗才能拿去跟門檻比：

$$\eta_n = \dfrac{1}{\left(\dfrac{1}{\eta_{ref}} - 1\right) \cdot (1 + r_{HL}) + 1}$$

$r_{HL}$（諧波額外損耗係數）：
- 額定功率 ≤ 90 kW：15%
- 額定功率 > 90 kW：25%

判定規則：實測 $\eta_{90} \geq \eta_n$ 才算達到該等級，由 IE1 逐級往上比對，能達到的最高等級即為結果。

## 常見誤區總結

1. **認錯標準**——PMSM/變頻驅動馬達套用 30-1 的邏輯或門檻值，兩份標準判定基準點不同，結果會錯
2. **忽略一體式排除條款**——pump/fan/compressor 若無法單獨測馬達本體效率，整份標準不適用，不是「算出來等級比較低」
3. **拿額定點效率當 η₉₀ 用**——判定基準是 90% 額定轉速，不是 100%，兩者效率通常有落差
4. **忽略諧波損耗修正 rHL**——少了這一步，門檻值會偏樂觀
5. **忽略運轉型態假設**——門檻表基準是連續運轉（S1），頻繁啟停的短時運轉型態直接套用會失真

按這五步驟走一遍，才是完整、站得住腳的 IE 等級判定，而不是「查個數字對一下表」這麼單純。

## 後記：真的做出來之後

寫這篇筆記的時候，功能其實還沒真的動工。這幾天把它做出來，才發現「查標準」跟「做出來能不能用」完全是兩件事。

**一個意外的心得：90% 位移，對模擬資料到底有沒有意義？** 這篇筆記裡寫的「為什麼要用 90% 轉速位移」，理由是避開變頻器內部電壓降造成的量測不確定性——但這是為了「實測」設計的考量。系統裡的效率地圖是 Motor-CAD 模擬出來的，直流匯流排電壓是自己設定的已知輸入，沒有「換一台驅動器結果不一樣」這種不確定性。這代表這套位移邏輯照搬過來，理由沒那麼站得住腳——但為了跟標準原文、未來如果有實測數據要對照時口徑一致，還是決定照做。

**還有一個觀察，可能比上面那個更值得記錄。** 小功率風扇馬達的 IE5 門檻其實訂得偏低（0.12kW 級距大概只要 70~80% 效率），稍微用心設計的 PMSM 風扇馬達效率動輒 85%+，很容易整張效率地圖都封頂在 IE5，看不出鑑別力。查標準查得再仔細，也不代表這個分級對「風扇馬達互相比較」這件事真的有用——這個問題比任何一個程式 bug 都更根本，還在評估要不要繼續留著這個功能。
